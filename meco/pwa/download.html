App-ka Android

Lacag-bixinta korontada, biilasha, wararka iyo ogeysiisyada (cod leh) — hal meel.

⬇ Soo deji APK
Version 2.3 · Android 7.0 ama ka sareeya
🌐 Ku fur browser-ka (app-ka web)
  1. Riix Soo deji APK, kadib fur faylka.
  2. Haddii la weydiiyo, oggolow “Install unknown apps” (Chrome / File manager).
  3. Riix Install → Open, kadib gal (login).
  4. Marka la weydiiyo ogeysiisyada riix Allow — si ay kor ugu soo dhacaan xitaa marka app-ku xiran yahay.
