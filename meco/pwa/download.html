Soo deji app-ka MECO

Lacag-bixinta korontada, biilasha, wararka iyo ogeysiisyada (cod leh) — hal meel.

⬇ Soo deji APK
Version 2.4 · Android 7.0 ama ka sareeya
🌐 Ku fur browser-ka (app-ka web)
  1. Riix Soo deji APK, kadib fur faylka.
  2. Haddii la weydiiyo, oggolow “Install unknown apps” (Chrome / File manager).
  3. Riix Install → Open, kadib gal (login).
  4. Marka la weydiiyo ogeysiisyada riix Allow — si ay kor ugu soo dhacaan xitaa marka app-ku xiran yahay.
📱 Fur app-ka MECO
iPhone · iOS 16.4 ama ka sareeya · Safari
  1. Bogga ku fur Safari (Chrome iPhone-ka kuma shaqeeyo rakibaadda).
  2. Riix Fur app-ka MECO, kadib riix badhanka ⬆ Share (hoosta).
  3. Dooro “Add to Home Screen” → Add. Icon-ka MECO ayaa ku soo baxaya shaashadda.
  4. Ka fur icon-ka MECO, kadib gal (login).
  5. Admin & staff: marka la weydiiyo “Daar Face ID” riix Daar — mar kasta oo app-ka la furo Face ID ayaa la weydiinayaa.
  6. Ogeysiisyada: marka la weydiiyo riix Allow.
💡 Face ID iyo ogeysiisyadu waxay si fiican ugu shaqeeyaan marka app-ka laga furo icon-ka Home Screen-ka, ee aan ahayn Safari tab.
